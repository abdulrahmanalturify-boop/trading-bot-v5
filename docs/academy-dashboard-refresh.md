# Academy learning dashboard — 14 October 2026

The academy opens on a learning dashboard instead of an introductory course showcase. A compact TURA Academy header leads into four real learner metrics, a resume card for the last unfinished course, an editable weekly lesson goal, seven days of activity, daily beginner practice and achievement milestones. Three starter paths and short course recommendations follow. The 37-course catalog retains all 26 beginner courses, adds sorting, and keeps the study notes, flashcards, videos and 12 practice labs.

Every lesson with a corresponding quiz question now offers immediate concept feedback. Advancing a lesson records its first completion; reviewing it does not add activity again. Weekly goals count newly completed lessons from Monday in the Saudi timezone. Challenge completion contributes to a day streak, without adding a lesson. Quiz accuracy uses the latest submitted score for each quiz and stays empty until a learner submits one. Historical progress contributes to all-time lesson totals without assigning invented dates.

Browser persistence stores learner activity, course resume state, quiz scores and the weekly goal with the existing browser progress. Compressed version 3 codes fit the existing 4,000-character storage limit; version 2 and old course-index codes still load. IDs, dates, scores and lesson indexes are bounded when loading. Storage remains per browser/device, with no account sync. A course counts as completed only after passing its final quiz.

The design stays scoped to the academy, uses TURA's blue/violet/cyan identity and follows the site's existing light-mode conversion. Responsive layouts reduce the metrics from four columns to two, simplify the campus header on phones and retain horizontal tab navigation. The academy revision hook loads the new code for existing server sessions.

Validation: Python 3.11-compatible syntax and 13 unittest/Streamlit AppTest checks. Coverage includes bilingual lesson navigation, all mini-course quizzes, course completion, notes/flashcards, all offline labs, daily challenge feedback, weekly goals, last-course resume, no duplicate activity, week boundaries, compressed full-history persistence and legacy migration. Desktop/mobile visual inspection and live-browser persistence could not be verified because the supported browser QA capability was unavailable.
